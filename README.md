# bdgovt.info জব নোটিফায়ার

bdgovt.info থেকে নতুন চাকরির বিজ্ঞপ্তি প্রতি ৪ ঘন্টায় স্ক্র্যাপ করে Telegram ও WhatsApp এ পাঠায়। GitHub Actions এ ফ্রিতে ২৪/৭ চলবে — আপনার PC অন রাখা লাগবে না।

## যা যা পাঠানো হবে

- হেডলাইন
- মোট পদ/ক্যাটাগরি
- শিক্ষাগত যোগ্যতা
- বয়সসীমা
- বেতন (গ্রেড উল্লেখ থাকলে সহ)
- বিজ্ঞপ্তি প্রকাশের তারিখ
- আবেদনের শেষ তারিখ
- যোগাযোগের তথ্য (এফ. এন. এফ কম্পিউটার & অনলাইন সার্ভিসেস, বরিশাল)

> শুধু একবার পাঠানো হবে — যে বিজ্ঞপ্তি আগে পাঠানো হয়ে গেছে সেটা `sent.json` এ সেভ থাকে, তাই বারবার একই পোস্ট আসবে না।

## ধাপ ১: GitHub রিপোজিটরি বানান

1. [github.com](https://github.com) এ একটা নতুন **Private** রিপো বানান (যেমন `bdgovt-notifier`)।
2. এই ফোল্ডারের সব ফাইল (`scrape.js`, `package.json`, `sent.json`, `.github/workflows/scrape.yml`, এই `README.md`) আপনার রিপোতে আপলোড/পুশ করুন।

```bash
cd bdgovt-notifier
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/bdgovt-notifier.git
git push -u origin main
```

## ধাপ ২: Telegram বট বানান (ফ্রি, সহজ)

1. Telegram এ `@BotFather` কে মেসেজ দিন, `/newbot` টাইপ করুন এবং নির্দেশনা অনুসরণ করে একটা বট বানান।
2. BotFather যে **token** দেবে সেটা কপি করে রাখুন (দেখতে অনেকটা `123456789:ABCdefGhIJKlmNoPQRstuVWxyz` এর মতো)।
3. এবার আপনার বানানো বটকে Telegram এ খুঁজে বের করে `/start` লিখে একটা মেসেজ পাঠান।
4. ব্রাউজারে এই লিংক খুলুন (token বসিয়ে):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
5. রেসপন্সে `"chat":{"id":XXXXXXXXX` — এই নাম্বারটাই আপনার **chat_id**।

## ধাপ ৩: WhatsApp সেটআপ (CallMeBot — ফ্রি পার্সোনাল API)

> এটা একটা আনঅফিসিয়াল ফ্রি সার্ভিস, পার্সোনাল ব্যবহারের জন্য জনপ্রিয়। অফিসিয়াল WhatsApp Business API ব্যবহার করতে চাইলে জানাবেন, সেটাতে খরচ ও ভেরিফিকেশন লাগে।

1. আপনার WhatsApp এ এই নাম্বারটা কন্টাক্টে সেভ করুন: **+34 644 59 71 68**
2. ওই নাম্বারে এই মেসেজটা হুবহু পাঠান: `I allow callmebot to send me messages`
3. কিছুক্ষণের মধ্যে একটা রিপ্লাই আসবে যেখানে আপনার **apikey** দেওয়া থাকবে।
4. আপনার নিজের WhatsApp নাম্বারটা country code সহ লিখে রাখুন (যেমন বাংলাদেশ হলে `8801XXXXXXXXX`, কোনো `+` বা স্পেস ছাড়া)।

## ধাপ ৪: GitHub Secrets যোগ করুন

আপনার রিপোতে যান → **Settings → Secrets and variables → Actions → New repository secret**। নিচের ৪টা secret যোগ করুন:

| নাম | মান |
|---|---|
| `TELEGRAM_BOT_TOKEN` | ধাপ ২ এর token |
| `TELEGRAM_CHAT_ID` | ধাপ ২ এর chat_id |
| `CALLMEBOT_PHONE` | ধাপ ৩ এর নাম্বার (যেমন `8801XXXXXXXXX`) |
| `CALLMEBOT_APIKEY` | ধাপ ৩ এর apikey |

## ধাপ ৫: টেস্ট রান করুন

রিপোর **Actions** ট্যাবে যান → "BD Govt Job Notifier" ওয়ার্কফ্লো সিলেক্ট করুন → **Run workflow** বাটনে ক্লিক করুন। এতে সাথে সাথেই একবার রান হবে (৪ ঘন্টার জন্য অপেক্ষা করতে হবে না) এবং আপনি Telegram/WhatsApp এ মেসেজ পাবেন।

এরপর থেকে এটা প্রতি ৪ ঘন্টায় (00:00, 04:00, 08:00 UTC ...) নিজে নিজেই চলবে।

## সীমাবদ্ধতা / জানার বিষয়

- সাইটের হোমপেজেই সব তথ্য থাকে বলে শুধু হোমপেজ থেকেই ডেটা তোলা হয়েছে — ভেতরের ডিটেইল পেজ bot-protection দিয়ে সুরক্ষিত থাকায় সেটা স্ক্র্যাপ করা যায়নি। তাই "মোট পদ/ক্যাটাগরি" ফিল্ডে সাইট যা দেখায় তাই (কখনো একসাথে বিস্তারিত ব্রেকডাউনসহ, যেমন ৬৯+৩৩+০১) দেখানো হবে।
- সাইটের HTML গঠন ভবিষ্যতে বদলে গেলে স্ক্রিপ্ট আবার ঠিক করা লাগতে পারে — আমাকে জানালে আপডেট করে দিতে পারব।
- CallMeBot ফ্রি/আনঅফিসিয়াল সার্ভিস, মাঝে মাঝে রেট-লিমিট বা ডাউনটাইম হতে পারে।
- একসাথে অনেক নতুন পোস্ট আসলে (প্রথমবার রান করলে) অনেকগুলো মেসেজ একসাথে আসবে — এটা স্বাভাবিক।
